# Runs

Use this directory for durable execution notes that future agents should be able
to reuse. Do not record routine command output unless it preserves an important
decision, failure mode, or verification result.

Use filenames like:

```text
YYYY-MM-DD-short-topic.md
```

Suggested structure:

```markdown
# Title

## Context

## Commands Or Evidence

## Outcome

## Follow-Up
```
