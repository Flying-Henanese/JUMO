# Plans

Put implementation plans here when a task has multiple ordered steps or should be
resumable across agent sessions.

Use filenames like:

```text
YYYY-MM-DD-short-topic-plan.md
```

Suggested structure:

```markdown
# Title

## Goal

## Scope

## Steps

## Verification

## Rollback Notes
```

Plans should be concrete enough that another agent can continue the work without
rediscovering the whole repository.
